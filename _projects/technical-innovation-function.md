## The brief

Woodhurst is a consultancy that works in an AI-first way, but it had no shared technical foundation. I founded the technical innovation function to build one and I manage it.

## What I built

A green-field Azure architecture using Terraform, Function Apps, Azure DevOps and Container App Jobs. It does three things:

- **Cuts cost.** Storage costs are down 60%.
- **Hosts the company's automations,** so internal tools run on one governed platform instead of scattered scripts.
- **Improves governance** across the firm's data and tooling.

Everything is infrastructure as code, so the environment can be rebuilt, reviewed and changed in the open like any other piece of software.
